Projects

Explore some of the projects I've been working on!

On this page you will find some of the various projects I have been working on during my time at NMIT or during my self directed study of various coding languages such as JavaScript, HTML, CSS, MySQL and more. This page will be updated with new projects as my learning progresses, so watch this space!

  • Hut Booking Tracker

    This Hut Booking Tracker was created by me during my SDV503 class in my first year at NMIT. This app was designed to track bookings for huts in the DOC hut network. This marked a major leap in my ability to create something using code. Although this project definitely has room for improvement, it still serves as a milestone for me in my coding journey.

  • Study Tracker

    An earlier project from my SDV503 class at NMIT. Made before the Hut Booking Tracker, it was designed to simply record how much time someone studied for and show a report of how much time they had spent studying over the course of a week.

  • freeCodeCamp HTML

    Over the course of my second semester at NMIT, I have been working on freeCodeCamp's responsive web design course. Part of which is the language HTML which, while being a relatively basic, still proved to be quite the challenge to understand the proper formatting as well as other important aspects of web design such as ARIA attributes and WCAG guidelines.

  • freeCodeCamp CSS

    Another part of freeCodeCamp's responsive web design course, CSS has been both exciting and confusing to get my head around. While I do enjoy the added styling ability which CSS provides websites and its ability to personalise them almost endlessly, I occassionally found some of the coding confusing until I understood specificity more in-depth so that styles don't overlap with one another.

  • freeCodeCamp JavaScript

    JavaScript. As incredibly flexible as it is mildly infuriating. I have used it to create simple command line applications, custom functions and course specific assessment work. Through it all I have seen how flexible it can be when designing web applications, I have also seen how its flexibility can hurt it somewhat. While its true that it adds interactivity to websites, JavaScript (at least in my experience) also is prone to tiny malfunctions that ultimately break the entire function.

  • CSA502 Computer Hardware

    During my CSA502 class at NMIT, I learned how to pull an entire computer apart and put it back together in the space of just a couple of hours. I found it incredibly fun to see the inner workings, cable management, design and layout of an everyday desktop pc and how everything fit together. Although seeing all the parts strewn about the table made me a tad nervous at the time, I had always wanted to pull one apart just to see how they work.

  • WEB504 Storefront Practice

    This is a simple responsive webpage which I designed in two hours during my WEB504 class (Coincidentally the same class I made this website in). While it only features two pages and relatively simple layout, it was still infinitely helpful to understand how a real website might be laid out and gave me insights into how to design this website.
